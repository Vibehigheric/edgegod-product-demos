# Bitcoin Merchant Reporting & Health Monitor

Original offline synthetic demo. Run `python run_demo.py` and `python -m unittest -v` here; open index.html.
No dependencies, network calls, customer records, credentials, wallet access or funds.
Demonstrates invoice reconciliation, duplicate/unmatched/unconfirmed exceptions, CSV/HTML/JSON,
simulated health alerts and Telegram DRY_RUN. File hashes establish integrity, not truth.
Use browser Print to save a PDF; a standalone generated PDF is not supplied.
